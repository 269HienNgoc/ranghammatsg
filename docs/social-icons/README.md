# Icon mạng xã hội cho footer

Chuẩn theo footer hiện tại (`footer.php`, khối "Kết nối với chúng tôi"): ảnh vuông 40×40 (`<img>` size-10, lg 36px),
bo góc 8px khớp `rounded-lg` của link, màu thương hiệu vẽ sẵn, nổi rõ trên nền footer `#003442`.
SVG chỉ gồm hình vẽ (không script, không link ngoài) → qua được bộ lọc `inc/svg-upload.php`.

Cách dùng: Tùy biến → Chân trang (Footer) → danh sách Mạng xã hội → thêm dòng: Tên, Link, Icon (tải file .svg ở đây lên).

| zalo.svg | Zalo |
| messenger.svg | Messenger |
